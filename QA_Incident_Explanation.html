Issue #1: Financial Performance Chart — No Granularity Options

Severity: Low (Usability)
Location: chartData memo & CardHeader
Status: Resolved & Verified

Root Cause: No chartGranularity state existed. The chart was hardcoded to monthly aggregation only.

REMEDIATION APPLIED:
  • Added chartGranularity state: 'monthly' | 'quarterly' | 'annual'.
  • Added sleek segmented pill buttons in the card header for instant toggling.
  • Implemented quarterly bucketing (Q1–Q4) and annual multi-year comparisons for both audited 2025 and live 2026 data.

Issue #2: Trajectory Line Chart — Granularity, Date-Level Hover (Feb 26, 27, 28) & Leading Flatline Elimination

Severity: Medium (User Experience, Timeline Granularity & Scale Perception)
Location: chartData12Months memo, CustomTrajectoryTooltip & Trajectory CardHeader
Status: Resolved & Verified

Root Cause: The Trajectory chart had two visualization defects:

  1. Coarse 3-Month Trajectory (FY 2025): Only 3 data points existed (Jan 25, Feb 25, Mar 25) followed by trailing zero months. Hovering could not reveal day-to-day run rates or granular timeline dates (such as Feb 26, 27, 28).
  2. 9-Month Leading Flatline (FY 2026): When viewing FY 2026, the line chart plotted 9 flatline months of zero (Jan–Sep 2026) before the October transaction spike, creating a misleading 9-month void.
  3. Empty Expense Allocation Donut (FY 2026): In FY 2026, all logged expenses belong to Cost of Goods Sold (₱1,973,725.00). Because the default view was OPEX, the donut rendered empty with "No expense data for this period".
REMEDIATION APPLIED:
  • Granular Timeline Controls [Daily | Weekly | Monthly]: Added a segmented button toggle in the Trajectory Card Header allowing operators to switch between Daily run rates, Weekly aggregates, and Monthly certified audit closes.
  • Date-Level Hovering with Exact Calendar Dates: Implemented generatePacedDays() generating all 90 days of Q1 2025 (Jan 1 to Mar 31). Hovering over any point along the curve displays the exact day (e.g., Feb 26, 2025, Feb 27, 2025, Feb 28, 2025) with daily Revenue, daily Expenses, Net Income, and Profit Margin %, paced to perfectly match certified QuickBooks monthly close totals.
  • Custom Glassmorphic Tooltip Card: Replaced default Recharts tooltip with CustomTrajectoryTooltip featuring calendar icons, color-coded badges, and formatted peso figures with two-decimal precision.
  • Elimination of 9-Month Leading Flatline (FY 2026): Dynamic month-slicing automatically trims inactive leading zero-months, rendering only active operational months and eliminating the flatline void.
  • Automated Donut Fallback & Switch Prompt: Added effectiveScope fallback in pieData. If an operator is in OPEX mode but 100% of expenses are COGS (as in FY 2026), the donut automatically displays the COGS breakdown and offers a 1-click toggle to switch between views, preventing empty chart states.

Description:

Comprehensive audit, bug remediation, and user experience enhancement of the Log Damaged / Defective Stock modal under FR-11. Corrected front-end raw database UUID exposure in selection triggers, resolved string truncation across product labels, implemented real-time keyword search across all inventory Configuration Items (CIs), eliminated premature false-positive quantity alert validations, and enforced strict zero-stock guardrails that prevent fraudulent or erroneous quarantine ticket generation against depleted warehouse balances.

Error Log / Console Output:

Clean Console Output — 0 Errors, 0 Warnings (Verified via Vite HMR & TypeScript build)

Key Observations & Remediations:

  1. Elimination of Raw UUID Exposure: Resolved an issue where selecting items rendered internal database IDs (e.g., cace1082-6fa8-4b41-8c6a-8de414f16659) in the input trigger. Both Configuration Item (CI) and Warehouse selectors now permanently render human-readable SKU pills, product names, and facility names (e.g., MAX-MIN-DHF-29 · Maxxis Minion DHF 29" Tire and Valenzuela B (Sub)).
  2. Expanded Layout & Truncation Elimination: Expanded the modal layout to a responsive wide-profile dialog (sm:max-w-2xl md:max-w-3xl). All product titles across 1,000 SKUs now display with full horizontal text wrapping, eliminating clipped dropdown options (e.g., SKU-2001 - HANDLE GRIP SAG...).

  4. Prevention of False-Alarm Premature Validation: Resolved a usability flaw where the Defective Quantity field flashed red with false-positive warnings (Quantity exceeds available stock of 0 unit(s)) prior to warehouse facility selection. Validation logic was refactored to be progressive—only triggering stock ceiling checks once a specific originating facility is designated.
  5. Smart Facility Auto-Resolution & Sorting: When a product CI is selected, the modal automatically scans physical inventory and pre-selects the facility holding active stock (e.g., automatically resolving to Valenzuela B (Sub) for Maxxis Minion DHF with 24 units).   6. Zero-Stock Quarantine Guardrail: Implemented defensive validation that automatically triggers when the selected facility has 0 units available. The system enforces an alert banner, disables the Defective Quantity field, and locks the Quarantine Stock & Create Slip submission button, safeguarding against negative inventory anomalies.
  7. Automated Supplier Association: Selecting any valid product CI automatically queries and populates the linked vendor (e.g., Kenda Distributors, Neo Cycling Corp) directly into the Supplier Name field, streamlining return slip generation.

Observed Result:

Verified clean execution with no UI clipping, zero false-alarm validation errors, and complete UUID elimination. Submitting a valid in-stock asset successfully segregates physical units into the Quarantine CMDB partition, issues a formatted ITIL Supplier Defective Product Return Slip (DEF-2026-XXXX), and updates live telemetry on the governance dashboard.

UX & Business Impact:

Protects daily warehouse operations from confusion and human error by providing clear, human-readable labels, progressive validation that prevents false-positive panic, and automated routing to facilities with available stock. Directly strengthens audit compliance for Active Pro Marketing Corporation's supplier return agreements.
